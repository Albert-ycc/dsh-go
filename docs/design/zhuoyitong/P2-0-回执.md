## 3. 对方案的修正（需要 P2-a / P2-b 看）

1. 方案 4.3 的 typemap 以 `Button` 为可点控件不成立：设置页的可点击节点主体是 `Row`/`Column`，标签在子 `Text` 里，`clickable=true` 且自身无文字的节点占 13/20、6/16、3/19、8/26（NOTES.md 第 5 节第 1 条）。
2. 方案 4.3「opacity 为 0 丢弃」会裁掉整个容器应用：容器窗口根 `android.widget.FrameLayout` 的 `opacity="0.000000"`，内容完整可见。
3. 方案 4.4 的 `replaceText` 宏缺一步提交：`text` 打入的字母停在输入法组词条里，要补 `keyEvent 2054` 才进框；读回应读 `SearchField` 子孙节点，外层 `Search` 的 text 为空；dump 更新有 1 秒以上延迟。
4. 方案 4.5 的 `launch` 缺 ability 时靠 `bm dump -n` 取 `mainAbility`，对容器应用不成立（`bm` 查不到），也不会出现在 `apps` 列表里。
5. 方案 4.3 的 `visible:false` 丢弃在这台机上是空操作：6 份夹具里 `visible` 全是 `"true"`。
6. 密码页截屏纯黑，带图 observe 在该页得到黑图；全黑图不能当读屏失败重试。

- 屏幕亮着的锁屏页、开关「关」态、密码掩码字符三项没有样本。
- `fixtures/` 下 `probe-app-home.dump.json`、`synthetic-settings.dump.json` 不是本次采集，来自 P2-a。
